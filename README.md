# 🌍 مستكشف العالم

تطبيق تعليمي تفاعلي للأطفال (٦–١٢ سنة) لتعلّم دول العالم وأعلامها وعواصمها بثلاث لغات: **العربية والإنجليزية والصينية** (مع طريقة النطق اللاتينية "بينين")، ويعمل **بلا إنترنت**.

## الأقسام
- **🗺️ خريطة العالم:** خريطة حقيقية بالقارات، تكبير بالإصبعين، بحث بالاسم أو العاصمة، وبطاقة لكل دولة فيها العلم والأسماء الثلاثة بالنطق، والعاصمة والقارة والمساحة والجيران ومَعلم ومعلومة طريفة والتحية بلغة البلد.
- **🛂 جواز السفر:** ختم لكل دولة تُفتح بطاقتها، وتقدّم لكل قارة، وجوائز. ولكل طفل جوازه المستقل.
- **🎮 الألعاب:** خمّن العلم، أين هذه الدولة؟ (على الخريطة)، ما العاصمة؟، ذاكرة الأعلام. والصعوبة تتغير حسب مستوى الطفل.
- **✈️ رحلة اليوم:** طائرة تطير كل يوم إلى دولة جديدة، مع سلسلة أيام متتالية.
- **🐪 رحلة ابن بطوطة:** ٢٢ محطة من طنجة إلى الصين ومالي، مع قصة لكل محطة.
- **🕋 العالم الإسلامي:** دول منظمة التعاون الإسلامي، ومكة والمدينة والقدس، وطرق الحج القديمة (المصري والشامي ودرب زبيدة).
- **👋 قل مرحباً:** التحية بلغات العالم بالنطق.
- **🦉 البومة المرشدة** وثلاثة مستويات: صغير، ومتوسط، وكبير.

## التحميل
كل تحديث على الفرع `main` يبني تلقائياً ثلاث نسخ تجدها في صفحة **Releases**:
- `WorldExplorer.apk`: أندرويد
- `WorldExplorer-Setup.exe`: ويندوز ١٠ و١١
- `WorldExplorer-web.html`: ملف واحد يفتح في أي متصفح

## للمطوّر
```bash
npm install
npm run dev            # تشغيل محلي
npm run build          # بناء dist/
npm run build:single   # ملف HTML واحد في dist-single/
npm run icons          # إعادة توليد الأيقونات من الرسم
```
- `scripts/content.mjs`: كل النصوص العربية المحرّرة (العواصم والمعلومات والتحيات وابن بطوطة وطرق الحج).
- `scripts/policy.mjs`: القرارات التحريرية لأسماء الدول والحدود.
- `scripts/build-data.mjs`: يولّد بيانات الدول والخريطة والأعلام.
